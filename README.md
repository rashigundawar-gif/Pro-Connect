# 💼 ProConnect – Professional Networking Platform

A modern full-stack platform designed to help professionals connect, communicate, and grow their network.

Built with **React.js (Frontend)** and **Node.js + Express.js (Backend)**, ProConnect provides secure authentication, real-time communication, profile management, and scalable cloud-based media storage.

---

# 🔥 Features

- 👤 **User Authentication & Authorization**
  - Secure Registration & Login
  - JWT-based Authentication
  - Password Encryption using Bcrypt

- 🤝 **Professional Networking**
  - Create and Manage Profiles
  - Connect with Professionals
  - Build Your Network

- 💬 **Real-Time Communication**
  - Instant Messaging
  - Socket.IO Integration
  - Live User Interactions

- ☁️ **Cloud Media Management**
  - Profile Picture Uploads
  - Cloudinary Integration
  - Secure Media Storage

- 🛡️ **Security Features**
  - Helmet Protection
  - Rate Limiting
  - Input Validation
  - Protected Routes

---

# 🛠️ Tech Stack

| Layer | Technology |
|---------|------------|
| Frontend | React.js + Vite |
| Backend | Node.js + Express.js |
| Database | MongoDB Atlas |
| Authentication | JWT + BcryptJS |
| Real-Time Communication | Socket.IO |
| Cloud Storage | Cloudinary |
| API Communication | Axios |
| State Management | React Query |
